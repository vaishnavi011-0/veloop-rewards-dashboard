# VELOOP Rewards Dashboard 🎮

A responsive, gamified rewards dashboard built with React and Vite. Track level progress, explore earning opportunities, and play a mini-game in an engaging rewards experience.

## ✨ Features

- **Level Progress:** Displays the current level, XP progress, and progress toward the next milestone.
- **Level Roadmap:** Shows completed, current, and locked levels.
- **Earning Opportunities:** Three interactive reward cards.
- **Gold Rush Mini-Game:** Play a timed game, track your score, view results, and replay.
- **Responsive Interface:** Designed to adapt to different screen sizes.

## 🛠️ Technologies Used

- React
- Vite
- JavaScript
- CSS
- HTML

## 🚀 Getting Started

### Prerequisites

Install Node.js and npm.

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate into the project folder:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
