# VELOOP Rewards Level-Up Dashboard 🎮

A responsive, gamified rewards dashboard built with React and Vite. Track level progression, explore earning opportunities, and enjoy a mini-game in a modern rewards experience.

## ✨ Features

- **Level Progress:** Displays the current level, XP progress, and progress toward the next milestone.
- **Level Roadmap:** Visualizes completed, current, and locked levels.
- **Earning Opportunities:** Three interactive cards showcasing earning opportunities.
- **Neon Memory Match:** A playable mini-game featuring card matching, difficulty settings, score tracking, results, and replay functionality.
- **Responsive Interface:** Designed for mobile, tablet, and desktop screens.
- **Interactive UI:** Includes engaging visual effects and helpful information tooltips.

## 🛠️ Technologies Used

## 🚀 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/vaishnavi011-0/veloop-rewards-dashboard.git
   ```

2. Navigate to the project folder:

   ```bash
   cd veloop-rewards-dashboard
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

### Production Build

To create a production build, run:

```bash
npm run build
```
